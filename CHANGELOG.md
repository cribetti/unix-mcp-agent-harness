- **Automated Red-Team Suite & Pre-Eval Gate (`test_redteam.py`, `eval.py`):** Added 7-test adversarial suite (`24/24` passing combined with `test_harness.py` in `6.59s`) and enabled `--security-gate` by default in `eval.py` so benchmarks abort if any sandbox check regresses (`c8a5adc`).
